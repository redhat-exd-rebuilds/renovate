Manages RPM package lockfiles generated by the [`rpm-lockfile-prototype`](https://github.com/konflux-ci/rpm-lockfile-prototype) tool.

### Supported Files

- **Input files**: `rpms.in.yaml` or `rpms.in.yml` - declares desired packages (no versions)
- **Lock files**: `rpms.lock.yaml` - contains resolved packages with exact EVR (Epoch:Version-Release) versions

### How It Works

This manager detects updates by running `caching-rpm-lockfile-prototype` during extraction. The tool queries RPM repositories and generates a new lockfile. By comparing the current and new lockfiles, updates are detected immediately without additional datasource queries.

### Requirements

The `caching-rpm-lockfile-prototype` tool must be installed and available in PATH.
